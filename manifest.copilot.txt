# claude-harness sync manifest, GitHub Copilot target
#
# Same pipe format as manifest.txt: kind|tier|repo-path|live-path
#
#   kind      shared    the file is reused verbatim from the claude/ tree. The
#                       skill format is identical across the two harnesses, so
#                       skills are installed from claude/skills/, never
#                       duplicated into copilot/.
#             authored  written for the Copilot target, lives under copilot/.
#   tier      lowest install tier that includes the file (bin/install-copilot.sh
#             --tier N installs every row with tier <= N). Tier 3 rows are
#             printed, not copied.
#   live-path relative to the Copilot config dir ($COPILOT_HOME, default
#             ~/.copilot). "-" means the file never leaves the repo.
#
# Read ONLY by bin/install-copilot.sh. The sync scripts (bin/export.sh,
# bin/import.sh) read manifest.txt and ignore this file entirely, because the
# Copilot config directory has no live counterpart to diff against at home.
# Every file listed here also carries a row in manifest.txt, which stays the
# repo-wide allowlist.
